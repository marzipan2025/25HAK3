# 25HAK3 — 한자 기출

한자능력검정 3급 기출문제 앱. 회차를 고르면 150문항을 훑고, 문항을 누르면 정답이 나온다.

Kotlin + Jetpack Compose, minSdk 26.

## 화면

- **회차 선택** — 35~113회(77개)를 최신순 격자로. 본문을 못 읽은 회차는 흐리게 두고 잠근다.
- **문제** — 검은 바탕 위에 문항 카드 하나. 카드 라운딩은 기기 화면 곡률에서
  바깥 여백 4dp를 뺀 값이라 화면 모서리와 동심원을 이룬다(23DBAP와 같은 방식).
  묻는 낱말을 화면 가득 얇게 세우고, 지문이 따로 있으면 원본 밑줄을 살려 아래에 붙인다.
  카드를 누르면 정답이 펼쳐지고, 그 문항에 나오는 한자의 訓音이 **모두** 따라 나온다
  (`銳( ) ↔ 鈍濁` 이면 銳·鈍·濁·利 넷 다). 좌우로 밀어 넘긴다.
- **바닥 한 줄** — 왼쪽 판정 원, 가운데 슬라이더, 오른쪽 판정 원이 벽에서 벽까지 채운다.
  슬라이더의 채워진 부분은 트랙 안쪽으로 4dp 들어가 테두리가 보이고, 0%에서는 정원,
  100%에서는 안쪽을 꽉 채우는 알약이 된다. 손잡이를 따로 두지 않고 채워진 끝이 곧
  위치이며, 문항 번호는 그 한가운데에 얹는다. 카드와의 간격은 판정 원 지름의 1/4.

## 모르는 문항 기록

아래 두 단추로 문항을 두 목록에 담는다 — 노랑 **애매하게 모름**, 빨강 **아예 모름**.
누르면 기록하고 다음 문항으로 넘어간다. 기록은 회차별로 남는다.

왼쪽 벽에 붙은 두 원이 그 목록을 여는 필터다. 원 안의 숫자가 담긴 문항 수이고, 켜져 있으면
흰 테를 두른다. 목록을 열면 카드 테두리가 그 색이 되고, 아래 원의 색이 바뀐다.

| 보고 있는 것 | 왼쪽 원 | 오른쪽 원 |
|---|---|---|
| 전체 | 노랑 · 애매하게 모름 | 빨강 · 아예 모름 |
| 노랑 목록 | 초록 · 외웠음 | 빨강 · 아예 모름 |
| 빨강 목록 | 초록 · 외웠음 | 노랑 · 애매하게 앎 |

초록은 그 목록에서 빼고, 다른 색은 그 색 목록으로 옮긴다. 어느 쪽이든 지금 보고 있는
목록에서는 빠지므로, 목록을 끝까지 비우는 것이 한 회차를 마치는 방식이 된다.

## 톤

01haka 다크 모드에서 그대로 가져왔다 ([Theme.kt](app/src/main/java/com/artbrain/hak3/Theme.kt)).
배경 `#1A1D23`, 한자 `#A8BAD6` 85%, 경계선 `#BAD0E2` 14%, 정답은 01haka 신호등 앰버 `#FFBD2E`.
본문은 시스템 산세리프, 한자만 Thin(w100)으로 크게 — 획이 보여야 하니까.

## 데이터

`app/src/main/assets/hanja3.db` — `../hanja-mock/data/hanja3.db`를 복사한 것.
원본 PDF에서 뽑는 과정은 [hanja-mock/data/README.md](../hanja-mock/data/README.md) 참고.

데이터를 다시 뽑았으면:

```bash
cp ../hanja-mock/data/hanja3.db app/src/main/assets/hanja3.db
```

DB 안의 `hunmeum` 표가 訓音을 대준다. 정답이 한자면 정답 글자로, 정답이 독음이면
문제에 나온 한자로 붙인다 — `수출` 아래 `輸 보낼 수 · 出 날 출`.

표는 세 겹으로 쌓는다. 우선순위가 높은 쪽이 이긴다.

1. **시험지 자체의 訓音 구역 정답** (689자) — 한국어문회가 쓰는 표현 그대로다.
2. `../hanja-mock/data/hunmeum_override.tsv` — 사전 표현이 대표훈음과 다른 글자를 손으로
   바로잡은 표. 훈음이 어색하면 여기에 한 줄 추가하고 `build_hunmeum.py`를 다시 돌리면 된다.
3. libhangul 한자 사전 — 나머지를 채운다.

## 폰트

시스템 CJK 폰트에는 Thin 굵기가 없어서 Noto Sans KR(SIL OFL)을 넣는다.
가변 폰트를 wght=100으로 굳히고 DB에 실제로 쓰인 3,267자만 남겨 828KB로 줄였다.

```bash
python3 tools/make_font.py     # fonttools 필요
```

## 아이콘

`~/Downloads/AppIcon_25HAK3.png` 한 장에서 굽는다. 적응형 아이콘은 108dp 중 안쪽
72dp만 보이므로 바탕은 원본의 노랑(#F4DC13)으로 깔고 그림은 안전 영역에 맞춰 줄인다.

```bash
python3 tools/make_icon.py     # Pillow 필요
```
